# Digital Complaint Management System

## Project Description
The Digital Complaint Management System is a web-based application developed using Python, Streamlit, and SQLite. It allows users to submit complaints digitally and helps manage complaint records efficiently.

## Objectives
- To provide an easy way to submit complaints.
- To store complaint records in a database.
- To manage and track complaint statuses.
- To reduce paperwork and save time.

## Technologies Used
- **Programming Language:** Python
- **Frontend:** Streamlit
- **Database:** SQLite
- **Libraries:** Pandas

## Features
- Submit complaints digitally.
- Select complaint categories such as Academic, Infrastructure, Hostel, Transport, Fees, and Other.
- Store complaint details in a database.
- Manage complaint statuses: Pending, In Progress, and Resolved.

## Installation and Execution
1. Install Python.
2. Install the required libraries:

   ```bash
   pip install streamlit pandas
   ```

3. Open the project folder in the terminal.
4. Run the application:

   ```bash
   streamlit run app.py
   ```

5. Open the local URL displayed in the terminal.

## Database
The application uses SQLite to store complaint records.
